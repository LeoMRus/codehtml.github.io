# Market Clock

Интерактивный календарь торговых сессий мировых бирж на 2026–2027 годы с часами, выбором часового пояса, праздниками и графиком открытия рынков.

**Сайт после активации GitHub Pages:** https://leomrus.github.io/codehtml.github.io/

## Публикация

В репозитории откройте **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

## Использование

Откройте сайт в браузере. Настройки часового пояса сохраняются локально, график и календарь переключаются по датам. Возможна печать из браузера (PDF).

## Данные

Официальные адреса календарей бирж встроены в `index.html`, но не отображаются. Расписания праздников записаны в коде и не обновляются автоматически через API.
